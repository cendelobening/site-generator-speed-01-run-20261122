# Fast Static Site Generator

A faster drop-in for makefun-site 1.0.0: `solve.js` renders a site's sources to
exactly the same output tree, byte for byte, but with templates pre-parsed once,
Markdown rendered straight from its lines, and strings built by join instead of
concatenation. Node 22 stdlib only, no dependencies.
